# v0.4 Lab evidence package

This retained research-side package tests a candidate coordination pattern through baseline, sham control, external ablation, perturbation, replication, and bounded version comparison. `experiment-intent.json` is the plain-language request, `experiment.json` is its immutable compiled design, `experiment-plan.json` is its explicit DAG, `experiment-fork.json` proves isolated lineage, and `lab-result*.json` plus `simple-result-projection.json` preserve the machine result and its non-overclaiming STUDY view.

`counterfactual.json` removes exactly one contradictory resource report at `AFTER_OBSERVATION` while holding declared variables fixed. `intervention-lesion-not-computable.json` is schema-only evidence that an undeclared internal lesion cannot execute. No file is a production-world mutation or a v0.5 regression fixture.
