# v0.1 Strategic Chamber Fixture

Deterministic multi-agent scenario (4 agents) coupling scarcity, infrastructure, production, trade, organizations, messaging, asymmetric information, and world-event pressure.

| File | Role |
|------|------|
| `world-seed.json` | Genesis strategic ecology |
| `agent-manifests.json` | Minimal manifests for 4 agents |
| `sample-trajectory.jsonl` | Example ordered events (not a scripted “winning” strategy) |
| `action-sequence.example.json` | Human-readable action outline |
| `initial-observations.json` | Sample observation summaries |
| `expected-final-state.json` | Post-trajectory state projection |
| `expected-final-state-digest.txt` | State digest |
| `expected-event-digests.jsonl` | Event digests |
| `expected-observation-digests.json` | Observation digests |
| `spectator-projections.json` | Derived WATCH projections (`mutates_world: false`) |
| `equivalence-boundary.json` | Comparison boundary |

This package **does not** replace `examples/v01-seed/` (full 24-type catalog). It adds strategic depth fixtures for C18–C26.
