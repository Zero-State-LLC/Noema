# Genesis theme packs — lore boundary

## Theme is not lore

```text
THEME
→ vocabulary, pressures, categories, aesthetic constraints

GENESIS
→ determines actual prehistory

WORLD HISTORY
→ determines actual events

LORE
→ later derived from evidence and cultural interpretation
```

A theme pack **must not**:

- fix a master chronology
- name villains or secret plots as canon
- create HumanPlayer vs AgentPlayer lore
- override observation/evidence rules
- add mechanics solely for genre flavor

## Application

Theme is applied **during Genesis preview** (naming, room prose, tension phrasing, institution labels).

It does **not** run every game cycle.

## Future lore labels

Names such as “The Relay Wars” or “The Black Archive” may appear later **only if** world history and evidence support them. The theme pack does not pre-authorize those as canon.
