## Narrow repair

`cohort bind-device-receipt` reads a private, explicitly run/label-bound projection
of the original seven-field `DeviceApprovalReceipt`. It checks raw Controller
hash, Agent device-token identity consistency, matching credential file and
unique receipt/binding references. It preserves the original values in a private
sidecar and writes only the existing `/1.0` approval fields. The runner receives
its own canonical Controller digest, exact file-byte digest, and content-addressed
references to the opaque Worker receipt strings. No digest is relabeled as a
different serialization. Explicit Controller and Player subjects are separated;
legacy identity fallback is retained when no explicit Controller ID is stored.
Receipt publication is non-overwriting, including same-slot concurrent replay.

See the procedure and retention limits in
[`../LCA2-GATE-B-COHORT-RUNNER.md`](../LCA2-GATE-B-COHORT-RUNNER.md#binding-retained-device-receipts-without-changing-their-meaning).
