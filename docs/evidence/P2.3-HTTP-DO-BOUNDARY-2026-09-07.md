## Real boundary exercised

`workers/noema/test/agent-http-do-boundary.test.ts` invokes the shipped
`worker.fetch`, actual JWT resolution/admission, actual internal `/command`
forwarding, `NoemaWorldDO.fetch`, world reducer and public projection handlers.
The fake namespace separates DOs by name, including enrollment and rate-limit
objects. Storage clones values on read/write and survives replacement of the DO
instance. These are platform fakes, not dummy application responses.

The only world target is `test.hosted-canonical.transport-boundary`. The fixture
sets production-mode admission but does not connect to production. All requests
are dispatched in-process. Global network fetch is forbidden and asserted unused.
No production secrets, email, live actions, deployments or paid services were used.

| Requirement | Concrete observed regression evidence |
| --- | --- |
| Supported discovery route | `/.well-known/noema-agent.json` advertises the actual `/v1/command` and `/v1/auth/device/token` routes. The command URI's path is executed through the local Worker. Canonical origin policy is preserved, not replaced with the fixture host. |
| Structured action discovery | Authenticated ENTER -> LOOK returns nonempty string `available_actions` and structured `affordances`. An available MOVE advertises `target_id: east`, which is submitted without a human parser and moves from `room.a` to `room.b`. |
| Agent authorization and identity | Real minted Agent credentials dispatch to the actual World DO. Legacy human/hybrid JWTs resolve to human principals without Player id/action scope and receive 403 before command dispatch. |
| Human / Admin separation | Human platform token receives 403. A token obtained through real `/v1/admin/session` cannot inhabit and receives 401. |
| Fail-closed credentials | Expired and missing-controller-type access tokens receive 401. Missing action scope receives 403, without World DO command dispatch. |
| Seal, world binding and structured input | Missing seal receives 401. Forbidden world override receives 403. `arguments.line` cannot override structured LOOK into MOVE. |
| Room bounds / forbidden behavior | Co-located INSPECT succeeds. After MOVE, the same entity receives `INSPECT_FAILED`. A non-exit hidden-room target receives `MOVE_REJECTED`. A mismatched `player_id` receives `FORBIDDEN`. Semantic action refusals preserve HTTP 200 plus `ok: false`. |
| Device enrollment refusal | Real advertised device routes create/persist a pending code, return `authorization_pending`, then return 401 after its advertised TTL. Unknown code also receives 401. No token is issued. |
| Public read boundary | A real MESSAGE is produced by commands and visible in the recipient's authenticated LOOK. Unauthenticated live/map projections contain public room data but exclude message text, hidden-room sentinel, Player id, inbox, affordances, situation and token. Unauthenticated inhabit LOOK receives 401. |
| Private cognition exclusion | A cognition-bearing command receives 400 before World DO command dispatch. |
| HTTP retry / fixture restart | Repeating a MOVE idempotency key after replacing the DO instance returns the same result from serialized storage. A fresh LOOK confirms the moved location. |
| DO defense in depth | Forged legacy human/hybrid principals are independently rejected at the actual internal DO `/command` handler with 403. |
